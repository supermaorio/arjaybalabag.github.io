# Arjay Freg Balabag — Portfolio

A responsive personal portfolio for a layout artist, graphic designer, and visual storyteller.

## Features
- Editorial-style responsive layout with mobile navigation
- Nine image-led portfolio projects
- Category filters for events, community, and design
- Accessible image lightbox with previous/next navigation and keyboard controls
- About, contact, and résumé sections
- Reduced-motion support

## Built with
Semantic HTML, CSS, and vanilla JavaScript. Hosted with GitHub Pages.

## Update the portfolio
1. Replace project images in `images/` while keeping the current filenames, or change the image paths in `index.html`.
2. Edit each project card title and `data-category` to change labels and filters.
3. Update the About and Contact copy in `index.html`.
4. Replace `resume.pdf` to publish a newer résumé.
5. Commit changes to `main`; GitHub Pages will publish from the configured source branch.

## Local preview
Open `index.html` in a browser.
